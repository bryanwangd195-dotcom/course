# BRYAN 課程入口網站

純靜態課程網站，可直接離線開啟，也可部署至 GitHub Pages。

## 內容

- 研究方法：2 章
- AI 互動式工業工程與管理概論：2 章
- 工業工程第 1 章已從 Word 擷取 6 張圖片，並同步顯示於課程導讀與完整教材；第 2 章 0 張圖片

## GitHub Pages 部署

1. 將本資料夾內的所有檔案上傳到 GitHub repository。
2. 在 repository 的 Pages 設定中，選擇由主要分支的根目錄發布。
3. 發布完成後，以 GitHub 提供的網址開啟。

網站只使用相對路徑，不需要資料庫或伺服器端程式。
